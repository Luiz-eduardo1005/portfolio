# Product Brief

Status: REVISADO — Luiz Eduardo, 2026-11-13

## Problem
Preciso apresentar minha formação, habilidades e projetos web (acadêmicos e pessoais) a recrutadores e parceiros de forma clara, acessível e atualizável.

## Users
Recrutadores, professores, colegas, clientes e organizações de estágio.

## Success measures
Todos verificáveis: site responsivo (T-003); 5 seções (RF-002); pelo menos 2 projetos com links válidos (RF-003, T-004); menu funcional (T-002); publicado no GitHub Pages (https://luiz-eduardo1005.github.io/portfolio/) e testado nele. Não há métricas de audiência coletadas.

## Scope
Dentro: site estático de uma página com Apresentação, Sobre mim, Competências, Projetos (três) e Contato (link do GitHub), com tema claro/escuro.
Fora: login, banco de dados, formulário que envie dados a servidores, coleta de CPF ou de qualquer dado pessoal, analytics, blog.
